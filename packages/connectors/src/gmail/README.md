# Gmail

Official upstream MCP server: `https://gmailmcp.googleapis.com/mcp/v1`

Garden uses the official Google Workspace Gmail MCP server with standard Google OAuth endpoints.

Requested scopes:

- `https://www.googleapis.com/auth/gmail.readonly`
- `https://www.googleapis.com/auth/gmail.compose`
- `https://www.googleapis.com/auth/gmail.labels`
- `https://www.googleapis.com/auth/gmail.modify`
