This handbook is for people who build Garden. Each page answers one kind of question.

| To                                    | Read                                            |
| ------------------------------------- | ----------------------------------------------- |
| Understand where state lives          | [How Garden is built](/handbook/architecture)   |
| Take a change from branch to merge    | [Ship a change to dev](/handbook/ship-a-change) |
| Look up what the `PR contract` checks | [Pull request contract](/handbook/pr-contract)  |
| Write or read a review                | [Review format](/handbook/review-format)        |

The pages live in `docs/handbook/` as MDX. To change a page, edit the file and open a pull request like any other change.

<Callout type="warn">
  Any signed-in user can read the handbook, and the page text ships in the app's
  public JavaScript. Don't put secrets or credentials here.
</Callout>
