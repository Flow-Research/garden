This handbook is for people who build Garden. It renders the repository's `docs/` folder, so every merged pull request updates it.

## Pages come in four kinds

- **Tutorials** walk you through a first run, start to finish.
- **Guides** give the steps for one task, such as writing a migration or deploying.
- **Concepts** explain why a part of Garden works the way it does.
- **Reference** lists facts to look up: paths, bindings, tokens, and open gaps.

**Decisions** record dated design choices. **Proposals** describe designs that are not built. **Archive** keeps historical snapshots that are no longer current.

## Change a page

Edit the file under `docs/` and open a pull request like any other change. Follow [Write a feature doc](./guides/develop/write-a-feature-doc.md) for new feature pages. `pnpm verify:docs` checks links, paths, and frontmatter in CI.

<Callout type="warn">
  Any signed-in user can read the handbook, and the page text ships in the app's
  public JavaScript. Don't put secrets or credentials here.
</Callout>
