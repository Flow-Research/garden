# Upcoming Features

AI Elements components installed but not yet wired into the UI.

## Queue

Display and manage task queues in the agent interaction panel.
Component: `@/components/ai-elements/queue`

Use cases:
- Show queued agent tasks with progress
- Display batch operations status
- Manage multi-step workflows

## Sandbox

Secure code execution environment embedded in chat.
Component: `@/components/ai-elements/sandbox`

Use cases:
- Run generated code in an isolated sandbox
- Preview computation results inline
- Execute data transformations with live output

## Task

Structured task cards with status tracking.
Component: `@/components/ai-elements/task`

Use cases:
- Break down agent work into visible sub-tasks
- Show task completion progress
- Track multi-step operations with individual statuses
